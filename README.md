## A few tips to actually hit this pace
1. **Hard timebox rule:** 15 min stuck = look at the approach (not full solution first — just the core idea), then implement it yourself.
2. **The 5-hour days (27th, 30th, 31st) are your recovery/catch-up buffer.** If you fall behind on a 2h day, push overflow problems into the next 5h day.
3. **Trees and Graphs are heaviest** (15 and 13 problems) — they're deliberately spread thin across almost every day so you build comfort with recursion/BFS/DFS gradually instead of cramming.
4. **Advanced Graphs, 2-D DP, and the hardest Trees/Linked List problems (K-Group Reversal, Serialize/Deserialize, Burst Balloons, Regex Matching) land late** in the schedule (Day 6 onward) — by then you'll have foundational reps in from earlier easier variants of the same patterns.
5. Re-solve, don't just re-read: even a rushed problem is only useful if you type the code yourself.

Good luck — this is aggressive but very doable if you stay disciplined on the timeboxing.
